# Dr. Shaukat Ali — Medical Portfolio

A modern, responsive medical portfolio website developed for **Dr. Shaukat Ali, MD, FACC**, an Interventional Cardiologist and Peripheral Interventionalist.

The website presents Dr. Shaukat Ali's professional background, medical education, clinical experience, achievements, areas of expertise, and contact information through a clean, responsive, and medical-focused user interface.

---

## 📌 Project Overview

This project is a **multi-page React portfolio website** designed to provide a professional digital presence for a medical specialist.

The website focuses on presenting professional information in a structured and accessible way while maintaining a modern medical visual style across desktop, tablet, and mobile devices.

---

## ✨ Features

* Professional doctor profile and introduction
* Responsive medical-focused user interface
* Multi-page navigation using React Router
* Professional biography and background
* Medical education and training information
* Clinical experience and professional roles
* Achievements and leadership information
* Areas of medical expertise
* Contact page
* Responsive navigation
* Light and dark theme support

## 🚀 Getting Started

### Prerequisites

Make sure the following are installed on your system:

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/UmarRao1/doctor-portfolio.git
```

### Navigate to the Project

```bash
cd doctor-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173/
```

---

## 🏭 Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🔀 Git Branching Strategy

The repository uses separate branches for the stable version and future development.

### `main`

Contains the current stable **multi-page medical portfolio**.

### `single-page-redesign`

Contains the ongoing development of a new single-page version of the portfolio.

The redesign is developed separately so that the stable multi-page version remains preserved on the `main` branch.
